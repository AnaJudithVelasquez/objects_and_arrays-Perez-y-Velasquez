## Descripción

Este repositorio contiene ejemplos básicos de Objects y Arrays en JavaScript.

En este trabajo explicamos:
- qué son los objects
- qué son los arrays
- algunos métodos importantes
- la mutabilidad en arrays
- un ejercicio práctico

Todos los ejemplos fueron desarrollados y ejecutados en Visual Studio Code usando Node.js.

---

## Archivos del proyecto

```bash
objects.js
arrays.js
mutability.js
exercise.js
```

### Descripción de cada archivo

- `objects.js`  
  Contiene ejemplos de objects y métodos como:
  - Object.keys()
  - Object.values()
  - Object.entries()

- `arrays.js`  
  Contiene ejemplos de arrays y métodos como:
  - push()
  - pop()
  - map()
  - filter()

- `mutability.js`  
  Explica la mutabilidad de los métodos de arrays, mostrando cuáles métodos cambian el array original y cuáles generan uno nuevo sin modificar los datos iniciales.

- `exercise.js`  
  Incluye un ejercicio práctico usando objects y arrays.

## Cómo descargar y ejecutar el proyecto

### 1. Clonar el repositorio

```bash
git clone URL_DEL_REPOSITORIO
```

---

### 2. Abrir la carpeta en Visual Studio Code

```bash
cd nombre-del-repositorio
```

---

### 3. Ejecutar los archivos

Ejemplo:

```bash
node objects.js
```

También se pueden ejecutar los demás archivos:

```bash
node arrays.js
node mutability.js
node exercise.js
```
